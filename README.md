# Relationships

A calm, private way to keep up with the people you care about. No paywall, no ads, no tracking, no accounts. (This repository is named "tend"; the app itself is called Relationships on the App Store and Play Store.)

## What it is

Add the people in your life and the Today tab shows only what needs you now: who you're overdue to reach out to, and any birthdays or important dates coming up. No streaks, no guilt trip, just who's due. Set a cadence for anyone you want a nudge about (weekly, every two weeks, monthly, quarterly, or none), and a reminder fires locally when it's time. It only asks for notification permission the first time you actually set a cadence or save a date, never before.

Each person gets their own page: notes, how you met, important dates, what they like, and an optional personality read (Enneagram type or attachment style) with plain guidance on how to show up for them. Log your catch-ups as you have them: a call, a text, in person, or something else, with a note if you want one.

Have the Conversation is a quiet space to prepare for a hard, honest talk before you have it: an apology, a hurt, something you've been holding back. Me is a short manual about yourself, in your own words (how you communicate, handle conflict, want support), that you can share with someone who loves you when you're ready.

Add people one at a time, or pick them from your contacts. Nothing is imported in bulk. You choose who. Export everything as a file whenever you want, to back it up or move to a new phone, and import it back in.

## Who it's for

Anyone who wants to be a better friend, partner, or family member and could use a little structure for it: a nudge before you go quiet on someone, a place to remember what matters to them, and help finding the words when a conversation is overdue.

## How to get it

Not on the App Store or Google Play yet. Run it locally, see below.

## Run it locally

```
git clone https://github.com/josh-approved/tend.git
cd tend
npm install
npm run ios        # or: npm run android, or: npx expo start
```

Requires Node and the Expo tooling (plus Xcode for the iOS simulator, or Android Studio for the Android emulator).
